# ch2cpacman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, Danish, arcade-styled browser game where scout patrols eat GPS pellets for points during a per-team timed phase, with an admin page for pellets, teams and a scoreboard, stored in cruttelut and hosted on GitHub Pages.

**Architecture:** One Vite + React SPA with hash routing (`#/` runner, `#/admin` admin). All state lives in four cruttelut collections read whole and filtered client-side; scores are derived from an append-only captures collection. Pure logic (geo, phase, score, queue, codes) lives in `src/lib/*.ts` with Vitest tests; React components are thin.

**Tech Stack:** Vite 7, React 19, TypeScript strict, Tailwind CSS 4 (`@tailwindcss/vite`), Leaflet 1.9, Vitest, GitHub Actions → Pages.

**Spec:** `docs/superpowers/specs/2026-09-17-ch2cpacman-design.md`

## Global Constraints

- Collections: `ch2cpacman_settings`, `ch2cpacman_teams`, `ch2cpacman_pellets`, `ch2cpacman_captures` at `https://cruttelut.kaasfrich.dk/rest/<name>`. PUT sends the full object with `_id`. POST never sends `_id`.
- Captures are append-only; dedupe on `(teamId, pelletId)` keeping the earliest `capturedAt`.
- Scoring window: `startedAt ≤ capturedAt ≤ startedAt + phaseMinutes*60s + 30s`.
- Team code alphabet `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`, length 4.
- Default pellet radius 25 m, default points 1, default phaseMinutes 10.
- All user-facing copy Danish, in `src/i18n/da.ts`.
- Theme tokens: yellow `#ffe600`, blue `#2121ff`, peach `#ffb8ae`, black `#000`; ghosts red `#ff0000`, pink `#ffb8ff`, cyan `#00ffff`, orange `#ffb852`. Font "Press Start 2P" for headings/numbers/buttons.
- Map tiles: CARTO Dark Matter `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`, attribution `© OpenStreetMap contributors © CARTO`.
- `vite.config.ts` `base: '/ch2cpacman/'`; hash routing, no rewrites.
- Node 22, pnpm.

### Task 7: Runner

**Files:** `src/runner/RunnerApp.tsx`, `CodeScreen.tsx`, `Briefing.tsx`, `RunnerMap.tsx`, `Hud.tsx`, `GameOver.tsx`, `useCaptureEngine.ts`, `src/components/*`

- [ ] `RunnerApp` loads settings, pellets, teams once (retry via ErrorBar). If no settings, no start or no pellets → full-screen `da.notSetUp`. Else if no stored team → `CodeScreen` (`normalizeCode`, match `teams.find(t => t.code === code)`, save id). Else load this team's captures once → `eatenIds`. Screen by `phaseState(team, phaseMinutes, now)`: `idle` → Briefing (until dismissed this session) then map + `TRYK START`; `running` → map + Hud + capture engine; `over` → map dimmed + GameOver. A 250 ms ticker drives `now`.
- [ ] Start: `api.teams.update({ ...team, startedAt: new Date().toISOString() })`; on failure show `da.startFailed`; on success flash `READY!` 1.5 s, `startJingle()`.
- [ ] `useCaptureEngine({ active, fix, pellets, eatenIds, team })`: on each new fix, `pelletsWithin`; for each: add to eatenIds, `enqueue({ teamId, pelletId, capturedAt: now, lat, lng, clientId: crypto.randomUUID() })`, `chomp()`; then `drain(api.captures.create)`; retry drain every 5 s while pending; expose `pendingCount`, `points` (sum of eaten pellet points).
- [ ] `RunnerMap` props `{ pellets, eatenIds, start, fix, heading, dimmed }`: Dark Matter tiles; pellet = `L.circleMarker` peach with glow class, radius 6 + points, tooltip permanent with points in arcade font; power-pellet pulse class when `points >= 3`; eaten pellets removed with a 300 ms scale-out CSS animation on a `divIcon`; Pac-Man `divIcon` SVG (yellow circle with mouth wedge) rotated by heading; fit bounds to pellets + start once.
- [ ] `Hud`: top bar `MM:SS` in arcade font (blinks red under 60 s), bottom `SCORE 000123` counting up; MuteToggle; `?` reopens Briefing as an overlay; "venter på netværk" when `pendingCount > 0` for > 10 s.
- [ ] `GameOver`: `GAME OVER` drop-in animation, points, pellets eaten, `gameOver()` sound once.
